# Supported Spring Boot Actuator Endpoints

Below is a comprehensive list of actuator endpoints which are supported by Spring Boot Admin.

Spring Boot Admin detects the endpoints exposed by each registered instance and only shows the corresponding views and
actions in the UI if the endpoint is available. Endpoints are grouped by the project providing them, as some of them
require additional dependencies on the client application (e.g. Spring Cloud).

## Spring Cloud Commons

These endpoints are provided by [Spring Cloud Commons](https://docs.spring.io/spring-cloud-commons/reference/spring-cloud-commons/application-context-services.html#endpoints)
and require `spring-cloud-context` on the classpath of the client application.

| Actuator Endpoint                 | Used in Spring Boot Admin                                          | Documentation Link                                                                                                                 |
|-----------------------------------|--------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------|
| `/actuator/env` (`POST`/`DELETE`) | _Environment Manager_ in the _Environment_ view                    | [Endpoints](https://docs.spring.io/spring-cloud-commons/reference/spring-cloud-commons/application-context-services.html#endpoints) |
| `/actuator/refresh`               | _Refresh context_ button in the _Environment_ view                 | [Endpoints](https://docs.spring.io/spring-cloud-commons/reference/spring-cloud-commons/application-context-services.html#endpoints) |
| `/actuator/restart`               | _Restart_ action in the applications list                          | [Endpoints](https://docs.spring.io/spring-cloud-commons/reference/spring-cloud-commons/application-context-services.html#endpoints) |

### Environment Manager

Spring Boot's `/actuator/env` endpoint is read-only. Spring Cloud Commons extends it so that properties can be set
(`POST`) and reset (`DELETE`) at runtime. Spring Boot Admin sends an `OPTIONS` request to `/actuator/env` and shows the
_Environment Manager_ only if the `Allow` response header contains `POST`.

To enable it on the client application:

```yaml
management:
  endpoint:
    env:
      post:
        enabled: true
        valid-keys-regex: "^(logging\\.level\\..*|my\\.app\\..*)$" # restrict the properties that may be changed
  endpoints:
    web:
      exposure:
        include: env, refresh
```

After updating properties, use _Refresh context_ to re-bind `@ConfigurationProperties` and re-create `@RefreshScope` beans
without restarting the application.

:::warning
Changing the environment at runtime is a powerful feature. Make sure the actuator endpoints are
[secured](../05-security/20-actuator-security.md) and limit the modifiable properties using
`management.endpoint.env.post.valid-keys-regex`.
:::

### Refresh vs. Restart

| Action                             | Endpoint            | Effect                                                                                                   |
|------------------------------------|---------------------|----------------------------------------------------------------------------------------------------------|
| _Refresh context_                  | `/actuator/refresh` | Reloads the configuration, re-binds `@ConfigurationProperties` and refreshes `@RefreshScope` beans. The application keeps running. |
| _Restart_                          | `/actuator/restart` | Closes and restarts the `ApplicationContext` (disabled by default in Spring Cloud).                     |

## Spring Cloud Gateway

These endpoints are provided by [Spring Cloud Gateway](https://docs.spring.io/spring-cloud-gateway/reference/spring-cloud-gateway-server-webflux/actuator-api.html)
and are only available on gateway applications.

| Actuator Endpoint                 | Used in Spring Boot Admin                                  | Documentation Link                                                                                                            |
|-----------------------------------|------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------|
| `/actuator/gateway/globalfilters` | _Gateway_ view                                             | [Global Filters](https://docs.spring.io/spring-cloud-gateway/reference/spring-cloud-gateway-server-webflux/actuator-api.html) |
| `/actuator/gateway/routes`        | _Gateway_ view (list, add and delete routes)               | [Routes](https://docs.spring.io/spring-cloud-gateway/reference/spring-cloud-gateway-server-webflux/actuator-api.html)         |
| `/actuator/gateway/refresh`       | _Refresh Routes Cache_ in the _Gateway_ view               | [Refresh](https://docs.spring.io/spring-cloud-gateway/reference/spring-cloud-gateway-server-webflux/actuator-api.html)        |

:::note
`/actuator/gateway/refresh` only refreshes the route cache of Spring Cloud Gateway. It is not related to
`/actuator/refresh` from Spring Cloud Commons.
:::
